# まとめるくん（仮称）

自作のChrome拡張機能（まもるくん・おさむくん・うながすくん）を、
ひとつの窓の中でタブで切り替えて使えるようにするハブ拡張です。

それぞれの拡張をサイドパネルや別ウィンドウで開くと窓が3つ並んでしまうので、
「1つの小窓でワンクリック切り替えしたい」という発想から生まれました。

## 仕組み

- 各拡張が `web_accessible_resources` で自分の `sidepanel.html` を
  **まとめるくんのIDにだけ**公開し、まとめるくんがそれを iframe で埋め込みます
- 埋め込めるのは自作の拡張どうしだけです。他人の拡張のUIは
  Chromeの設計上、別の拡張から起動・埋め込みできません
- 各拡張は iframe の中でもそれぞれ自分の `chrome.storage` を使うので、
  データは今までどおり各拡張のものがそのまま見えます
- 一度開いたタブの iframe は切り替えても破棄しません
  （まもるくんの録音を裏で続けられるようにするため）

## 使い方

- ツールバーのアイコンでサイドパネルが開きます
- ヘッダーの ⧉ で独立ウィンドウに切り離し、⇥ でサイドパネルに戻せます（おさむくん方式）
- 上のタブで3つの拡張を切り替えます

## 権限

`sidePanel` / `storage` の2つだけです。外部通信はありません。
（`chrome.windows` は権限宣言なしで使える範囲だけ使っています）

## 開発メモ

- `manifest.json` の `key` は**公開鍵**で、開発版でも拡張IDを
  `mdheihoolmkhoebieolpoacbfcmccnha` に固定するためのものです。
  対になる秘密鍵は `dev/`（gitignore対象）にあり、リポジトリには入れません
- 開発版などIDが違う相手を埋め込むときは、画面の ⚙ からIDを上書きできます

## テスト

```
npx @puppeteer/browsers install chrome@stable
CHROME_FOR_TESTING=<上で入ったパス> node test/hub_e2e.mjs
```

Chrome for Testing に4拡張を読み込み、CDP経由で
埋め込み・タブ切替・切り離しウィンドウまでを自動で確かめます（22項目）。
